# Overview

Practice one interview question or one coherent career story.

## Steps

1. Accept an explicit question or use the deterministic question-bank tool.
2. Retrieve multiple plausible experiences when useful; do not select a winner
   on the user's behalf.
3. Practice concise context, action, reasoning, evidence, outcome, and learning.
4. Let the user mark the preferred story or angle explicitly.
