WORK-BRAIN-SOP-CLOSE-DAY v1

# Overview

Optionally help the user reflect at the end of a day.

## Steps

1. Read current state and today's recent work.
2. Check for outcomes, unfinished loops, commitments, and tomorrow's next
   actions without reconstructing the entire day.
3. Commit only what the user actually discussed. Journal correctness does not
   depend on this workflow being run.
