# Overview

Help the user reason through one coherent professional problem.

## Steps

1. State the problem and what decision or belief is being examined.
2. Probe assumptions, evidence, alternatives, failure modes, reversibility,
   and what would change the user's mind.
3. Capture the decision, expected signal, next action, and unresolved questions.

Do not be contrarian for its own sake. Preserve meaningful changes in belief.
